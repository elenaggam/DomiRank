## Results

The results obtained for each part of the work can be found in the folders whose names start with `results`.

---

## Functions

The `.py` files whose names start with `functions` contain the functions used to obtain all of the results.
The suffix of each file indicates the corresponding part of the work.

---

## Obtaining Results

The results were obtained using the `.py` files whose names start with `run` or `plot`.

These files include execution examples that illustrate how to use the code and reproduce the obtained results. However, they can and should be adapted depending on the specific results to be computed.
